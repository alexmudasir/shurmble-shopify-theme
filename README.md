# Shurmble — Shopify Theme (OS 2.0)

A real Shopify OS 2.0 theme for the Shurmble cookie store, converted from the static demo.

## What is included

- 18 sections: announcement bar, header, hero flavour switcher, marquee, trust row, Build Your Own Box, best sellers, steps, shop grid, gifting, story, reviews, footer and more
- Real Shopify products, cart and checkout — the demo checkout was removed
- Build Your Own Box as a real product with line-item properties
- Demo cookie data as a fallback if the store has no products yet

## Setup

1. Create a Shopify store and set the currency to PKR.
2. Create the 8 cookie products with pack-size variants, plus a "Cookies" collection.
3. Create the "Build Your Own Box" product (Box of 4 / 6 / 8 variants) and select it in the section settings.
4. Set shipping (Rs. 250 flat, free over Rs. 3,000) and payments, including Cash on Delivery.
5. Upload this theme in Online Store → Themes → Add theme → Upload ZIP, then publish it.

See `SHOPIFY-THEME-README.md` in this repository for the full product and price table.
